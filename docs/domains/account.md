# 계정 — 로그인 · 가입 · 약관 · 탈퇴

누가 어떤 역할로 들어오고, 어떻게 나가는지입니다.

---

## 흐름

```
카카오 로그인 ─→ 회원가입(역할 고르기) ─→ 약관 동의 ─→ 서비스 이용
   가입 미완료         기관이면 기관 생성         동의 전엔 다른 API 403
```

- 기관과 보호자 모두 카카오로 로그인합니다. 처음 로그인하면 **역할이 없는 가입 미완료 회원**이 생깁니다
- 가입 미완료 회원은 세션 조회 · 가입 · 로그아웃 · 탈퇴 외의 API가 `403 SIGNUP_NOT_COMPLETED`로 막힙니다
- 약관에 동의하기 전에는 세션 조회 · 약관 동의 · 로그아웃 외의 API가 `403 TERMS_NOT_AGREED`로 막힙니다

---

## 1. 로그인

- 로그인 전 과정을 백엔드가 맡습니다. 카카오 회원번호만 받고 닉네임 등 사람 이름은 저장하지 않습니다
- 로그인 상태는 httpOnly 쿠키의 JWT입니다. 3시간짜리이고, 쓰는 동안 남은 시간이 절반보다 적으면 자동으로 늘어납니다. 처음 로그인부터 12시간에 끝납니다
- 쓰기 요청은 `XSRF-TOKEN` 쿠키 값을 `X-XSRF-TOKEN` 헤더로 보내야 합니다
- 로그아웃하면 그 로그인을 서버에 무효로 남깁니다. 늘어난 출입증까지 함께 막히고, 같은 회원의 다른 로그인은 그대로입니다
- 카카오 계정 없이 테스트할 때는 개발용 로그인(`/api/v1/dev/login?as=…`)을 씁니다 — [backend/README.md](../../backend/README.md#카카오-계정-없이-테스트하기-개발용-로그인)

## 2. 회원가입

역할을 고릅니다. **역할은 바꿀 수 없습니다.**

- **보호자** — 역할만 보냅니다
- **기관** — 기관명 · 종류(학교 · 발달센터 · 활동보조) · 사업자등록번호를 함께 보내고, 이때 기관이 새로 생깁니다. 기관 하나에 계정 하나입니다
  - 사업자등록번호는 숫자 10자리 형식만 보고 진위는 확인하지 않습니다. 이미 등록된 번호는 거절합니다
  - 기관마다 보호자에게 알려 주는 **기관 코드**(고정 8자리)가 있습니다. 기관 정보 화면을 처음 열 때 만들어집니다

## 3. 약관 동의

- 보호자는 서비스 이용약관 · 개인정보 처리방침, 기관은 기관용 이용약관 · 개인정보 처리방침 · 아동 정보 보호 서약에 모두 동의해야 합니다
- 동의 화면이 읽은 약관의 **판**을 함께 보냅니다. 그 사이 약관이 바뀌었으면 아무것도 기록하지 않고 409입니다
- 약관 본문은 로그인 없이 볼 수 있습니다 (`backend/src/main/resources/terms`)

## 4. 기관 담당자 넘기기

담당자가 바뀌어도 기관의 명부와 기록은 그대로 둡니다.

1. 지금 담당자가 **인계 코드**(8자, 12시간, 일회용)를 받아 후임에게 건넵니다. 다시 받으면 이전 코드는 못 씁니다
2. 후임이 카카오로 로그인해 회원가입에서 기관 정보 대신 인계 코드를 넣으면 같은 기관의 담당자가 됩니다
3. 이전 담당자 계정은 탈퇴로 정리됩니다

회원 탈퇴가 꺼져 있으면 담당자 넘기기도 쓸 수 없습니다.

## 5. 탈퇴

**보호자와 가입을 마치지 않은 회원만** 직접 탈퇴할 수 있습니다. 기관 담당자는 담당자 넘기기로 나갑니다.

- 카카오 연결을 끊고 → 아이 연결 · 내 공유 동의 · 인사이트 열람 권한 · 기다리던 기관 연결 요청을 거두고 → 카카오 회원번호를 지우고 탈퇴 표시를 합니다
- 같은 기관에 **다른 보호자의 동의가 남아 있으면** 그 기관 공유는 계속됩니다
- 같은 카카오 계정으로 다시 로그인하면 새 회원으로 가입부터 합니다
- 몇 초 안에 끝나면 204, 아니면 202로 접수만 알리고 백그라운드에서 끝냅니다. 처리 중에는 다른 API가 `409 WITHDRAWAL_IN_PROGRESS`, 끝나면 `401 ACCOUNT_WITHDRAWN`입니다
- 사용자가 카카오 쪽에서 먼저 연결을 끊으면 카카오가 **연결 해제 웹훅**을 보냅니다. 보호자 · 가입 전 회원은 같은 정리를 하고, 기관 담당자는 계정을 남깁니다
- 서버가 탈퇴를 열지 않았으면(`WITHDRAWAL_ENABLED=false`) 탈퇴 버튼이 숨겨지고 API는 404입니다

## API · 테이블 · 코드

**API** (`/api/v1`)

- `/auth/me` (세션 조회 · 탈퇴) · `/auth/signup` · `/auth/terms` · `/auth/logout` · `/terms` (약관 본문)
- `/institutions/me` (내 기관 · 기관 코드) · `/institutions/me/handover` (인계 코드 발급 · 취소)
- `/webhooks/kakao/unlink` (카카오 연결 해제 웹훅) · `/dev/login` (개발용, 설정으로 켤 때만)
- 카카오 로그인 진입은 `/oauth2/authorization/kakao`

**테이블** — `users` · `organization` · `terms_agreement` · `revoked_session` (로그아웃한 로그인) · `organization_handover` · `kakao_unlink_webhook` ([db/schema.md](../db/schema.md))

**코드** — `backend/.../service/user` · `service/organization` · `global/security` · `global/jwt`
