# 아이 · 보호자 — 등록과 연결

아이가 기관 명부에 오르고, 보호자와 연결되는 과정입니다. 연결된 뒤 무엇을 공유할지는 [동의](consent.md)에서 정합니다.

---

## 세 가지 연결

```
아이 ── 명부 ── 기관        기관이 등록하거나, 보호자의 연결 요청을 수락하면 오름
 │
 └── 연결 ── 보호자         초대 코드로 연결. 기관 구분 없이 아이 하나에 한 번
```

- **명부**는 기관마다 따로입니다. 아이 하나가 여러 기관 명부에 오를 수 있습니다
- **보호자 연결**은 기관과 상관없는 전역 연결입니다. 한 번 연결되면 아이가 다니는 모든 기관에 대해 보호자입니다
- **연결은 동의가 아닙니다.** 명부에 오르고 보호자가 연결돼도, 보호자가 그 기관에 동의하기 전에는 매칭 후보가 아닙니다

---

## 1. 기관이 아이를 등록

1. 기관이 이름 · 생년월일 · 관리번호로 아이를 등록합니다. 아이 상태는 `PENDING_CONSENT`로 시작합니다
2. 등록과 함께 **초대 코드**가 나옵니다. 기관이 카톡 등으로 보호자에게 직접 보냅니다
3. 보호자가 가입한 뒤 코드를 입력하면 아이와 연결됩니다

- 관리번호는 필수이고 같은 기관 안에서 겹칠 수 없습니다. 이름 · 생년월일이 같은 아이도 한 기관에 두 번 등록할 수 없습니다
- 초대 코드는 **10분 · 일회용**입니다. 한 아이에 여러 개를 발급해 둘 수 있고, 쓸 수 있는 코드만 목록에 보이며 취소할 수 있습니다
- 코드 입력은 하이픈 · 공백 · 소문자를 무시합니다. 이미 연결된 아이의 코드는 쓰지 않은 채 남습니다

## 2. 보호자가 다른 기관에 연결 요청

이미 연결된 아이를 새 기관에 붙일 때는 보호자가 **기관 코드**로 요청합니다.

1. 보호자가 기관 코드로 기관을 찾고, 아이를 그 기관 명부에 올려 달라고 요청합니다
2. 기관은 연결 요청 목록에서 관리번호를 넣어 **수락**하거나 **거절**합니다. 같은 아이에 보호자 여럿이 요청했으면 한 항목으로 묶이고 함께 처리됩니다
3. 수락되면 아이가 명부에 오르고, 그때부터 보호자가 그 기관에 동의할 수 있습니다

거절은 보호자에게 따로 알리지 않고, 보호자는 다시 요청할 수 있습니다.

## 3. 끊기

| 누가 | 무엇 | 결과 |
| --- | --- | --- |
| 기관 | 명부에서 빼기 | 그 기관 동의가 꺼지고(`ROSTER_REMOVED`) 기관 열람 권한을 거둠 · 쓸 수 있는 초대 코드 취소 · 관리번호는 다시 쓸 수 있음. 아이와 보호자 연결은 그대로 |
| 기관 | 보호자 연결 해제 | **우리 기관 코드로 연결된 보호자만** 해제할 수 있음. 전역 연결이라 모든 기관에서 끊김 |
| 보호자 | 아이 연결 해제 | 그 보호자의 동의와 열람 권한이 꺼짐(`GUARDIAN_UNLINKED`) |

이미 AI가 처리 중인 일은 명부에서 빼도 멈추지 않을 수 있습니다.

---

## 돌봄 정보

보호자가 아이의 **알레르기와 복용약**을 적어 둡니다. **기관에는 공유하지 않습니다.**

- 연결된 보호자 모두가 보고 고칠 수 있고, 나중에 저장한 쪽이 이깁니다 (통째로 덮어씀)
- 목록마다 20개, 글자는 30자까지입니다

## 상태

| 대상 | 상태 |
| --- | --- |
| 아이 | `PENDING_CONSENT` 동의 전 · `ACTIVE` 동의 있음 · `SUSPENDED` 동의 모두 꺼짐 ([동의](consent.md)) |
| 초대 코드 | `PENDING` → `ACCEPTED` · `CANCELLED` (만료는 시각으로 판단) |
| 기관 연결 요청 | `PENDING` → `ACCEPTED` · `REJECTED` · `CANCELLED` |

## API · 테이블 · 코드

**API** (`/api/v1`)

- 기관: `/institutions/me/children` (명부 · 등록 · 빼기) · `/{childId}/invitations` (초대 코드) · `/{childId}/guardians` (연결된 보호자) · `/institutions/me/link-requests` (연결 요청 수락 · 거절)
- 보호자: `/guardians/me/invitations/accept` · `/guardians/me/children` (내 아이 · 연결 해제) · `/institutions/lookup` · `/children/{childId}/institutions` (기관 코드로 연결 요청) · `/children/{childId}/care-info`

**테이블** — `child` · `child_organization` (명부) · `invitation` · `child_guardian` · `child_organization_request` · `child_care_info` ([db/schema.md](../db/schema.md))

**코드** — `backend/.../service/child` · `service/invitation`
